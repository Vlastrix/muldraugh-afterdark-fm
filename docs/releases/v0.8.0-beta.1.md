# Muldraugh Afterdark FM 0.8.0-beta.1 [B42.21]

Works with Project Zomboid Build 42.21 (singleplayer). This prerelease includes experimental multiplayer car radios: two-player Pear audio and shared controls were confirmed by the user on Build 42.21. Latest volume/tuning changes, placed radios, dedicated servers and larger groups still need live validation.

## Changes

- Stream the supplier's actual Pear audio through Zomboid's existing server connection. Only suppliers need Pear; every listener needs the mod and Afterdark FM Connector.
- Use my Pear ownership, shared Previous / Pause / Resume / Next controls, server permission checks and bounded audio/command queues.
- Shared radio volume and remote listener distance attenuation. Personal listening volume affects only received audio. The supplier hears Pear directly; owner distance attenuation remains pending.
- Singleplayer and Multiplayer radios (Steam) panels share one Connector window. The app starts disconnected and prevents both modes running together.
- Tune to 94.6 MHz, with native timed tuning and channel-panel refresh. New blue artwork and app icon show the updated frequency.

## Install

Extract AfterdarkFMConnector-Windows-0.8.0-beta.1.zip and run AfterdarkFMConnector.exe. No Python installation is needed. Keep the included runtime notices and instructions. Subscribe to Workshop item 3821956623, Mod ID PearCarRadio.

For multiplayer, update the server and both clients. Disable AfterdarkGameLab and duplicate local development copies. Everyone presses Start in the Multiplayer radios (Steam) panel. Suppliers first check Allow Use my Pear, select their process and authorize Pear's API Server plugin at 127.0.0.1:26538 with Auth at first. In a powered car radio, tune to 94.6 MHz and press Use my Pear.

Windows suppliers need process capture support (build 20348 or later; Windows 11 recommended). Listeners do not need Pear or a music account. Read QUICK_START.txt for both modes. SHA256SUMS.txt covers the attached player ZIP and quick-start file.

## Validation and limits

Automated checks cover the Lua/file transport harness, real Opus encoding/decoding, permissions, takeover, command ordering, volume restoration, UI integration, mode mutual exclusion and clean shutdown. The packaged EXE is smoke-tested with its GUI, native capture imports and codec. These checks do not establish full multiplayer compatibility.

Two-player car audio and shared controls have user validation. Further live testing is required for latest shared-volume/tuning fixes, placed radios, dedicated servers and larger groups. Held inventory radios, in-game song URL entry, directional audio and multiple-source mixing are excluded. Keep Pear and Connector open while playing. Restart after updating and retune old saved radios to 94.6 MHz.
